# Visual & Brand Checklist

## Per asset

- **Artwork matches the name**: the album cover shown is the actual cover for the album and artist named (correct edition, not a single's cover)
- **Amazon Music logo** present, in the same position and size on every frame, and not distorted, cropped, or recolored
- **Text legibility**: no text cut off, overlapping artwork or graphics, or running outside safe margins; long titles wrap cleanly (no single-word orphan lines unless intended)
- **Layout consistency**: shared elements (arrows, labels, cards, play buttons) are in the same position, size, and color across frames
- **Image quality**: no visible pixelation, compression artifacts, or stretched images
- **Explicit content**: if an album cover shows a Parental Advisory label, note it in case the placement requires a clean version

## Across the set

- **Frame count and sequence**: no missing or duplicate frames (Frame01...FrameNN)
- **Aspect ratio** matches the file name and the platform (4x5, 9x16, 1x1)
- **File naming** is consistent across the set: job number, platform code, campaign name, ratio, frame number, round/version (e.g., `LAT260935_IGC_Ciclo Emocional_4x5_Frame01_SK_R02V01.jpg`). Flag any file whose round/version or other fields don't match the rest.
- **No duplicate artists or albums** across frames unless intended

## Video-specific

- **Supers on screen long enough to read**: roughly 1 second per 3–4 words, with a 1.5s minimum. Flag anything that flashes by.
- **Safe zones for 9x16**: keep text and logos clear of the top ~14% and bottom ~20% (platform UI) and the right edge (like/share buttons)
- **End card**: Amazon Music logo and CTA present, held long enough to read, and the last frame isn't a black or flash frame
- **Consistency**: font, color, and position of recurring supers match across the edit
- **Technical**: no black/flash frames mid-edit, no stutters or frozen frames, aspect ratio and resolution match the file name and spec, no burned-in timecode or watermarks left over from review
- **Captions** (if burned in): match the VO script word for word, with the same spelling and accent rules as the copy checklist
