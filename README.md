# Movement Strategy Plugins

Team plugins for Claude Cowork.

## Install (one time)

1. In Claude, go to **Customize → Plugins → Add marketplace**
2. Paste this repo's link
3. Install **Content QC**
4. Turn on **Sync automatically** so you get updates

## Plugins

- **Content QC**: share a Drive or Frame.io link, video, or still and say "QC this"
